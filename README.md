# Field Ops - Painel do Supervisor

## Sobre o projeto

O Field Ops é um protótipo de sistema desenvolvido para auxiliar na gestão de inspeções realizadas em campo.

O projeto tem como foco o **Painel do Supervisor**, permitindo visualizar e organizar informações relacionadas a clientes, locais, equipamentos, checklists e inspeções.

O objetivo é facilitar o acompanhamento das atividades de campo e fornecer ao supervisor uma visão geral das inspeções, seus status e possíveis não conformidades.

## Objetivo

O projeto foi desenvolvido como um protótipo visual, com o objetivo de demonstrar como poderia funcionar uma plataforma de gerenciamento de inspeções.

Entre as principais funcionalidades planejadas estão:

- Visualização geral das inspeções;
- Cadastro e gerenciamento de clientes;
- Gerenciamento de locais e equipamentos;
- Criação e gerenciamento de checklists;
- Planejamento de inspeções;
- Atribuição de inspeções aos técnicos;
- Acompanhamento do status das inspeções;
- Revisão dos resultados das inspeções;
- Visualização de não conformidades;
- Exibição de alertas e indicadores.

## Tecnologias utilizadas

- **HTML5** - Estrutura das páginas;
- **CSS3** - Estilização e identidade visual;
- **Bootstrap 5** - Layout responsivo e componentes da interface;
- **Bootstrap Icons** - Ícones utilizados na interface;
- **Git e GitHub** - Controle de versão e armazenamento do projeto.
